本项目将原始 `.bin` 信号转换为包含时域特征、频域特征和类别标签的 NumPy 数据集，供后续分类模型使用。

默认流程为：扫描文件并解析标签、按文件分层划分数据集、在各集合内预处理和切片、训练集增强、逐切片标准化和 FFT 特征提取。小波参数为 **sym4、3 层分解、阈值系数 0.40**。

本版本先划分原始文件，再分别切片，因此同一文件及其增强样本只属于一个数据子集。默认切片长度为 **1 秒**、步长为 **1.5 秒**，训练增强包括时间平移、时间缩放和高斯噪声。

本文将提供的代码保存为 `build\_dataset.py` 作为运行示例；使用其他文件名时，相应修改运行命令。

## 2\. 数据准备

将代码保存为项目目录下的 `build\_dataset.py`，并创建 `data` 文件夹存放原始数据。

|路径|内容|
|-|-|
|`build\_dataset.py`|数据集生成脚本|
|`data/`|原始 `.bin` 文件|

### 原始文件格式

* 文件按 `np.uint16` 读取，即每个采样点占 2 字节，并采用运行机器的本机字节序。
* 文件应为不含文件头的连续单通道采样数据；代码没有解析文件头或拆分交错多通道数据的逻辑。
* 默认原始采样率为 **1,000,000 Hz**，须与实际采集设置一致。
* 默认每个完整切片需要 **1 秒**信号，即 **1,000,000 个原始采样点**。
* 脚本只扫描 `input\_dir` 直接包含的 `\*.bin` 文件，不递归扫描子目录。
* 不足一个完整降采样块的尾部数据会被丢弃；按步长定位后，仅保留完整切片。空文件和处理失败的文件会在预处理时被跳过。

扫描阶段打印的“有效测量文件”仅表示文件名能被解析为标签，尚未检查文件内容。代码注释中的“120 个文件”是数据规模描述，程序并不要求或检查文件总数必须为 120。

### 文件命名与标签

建议使用 `类别-编号.bin` 格式，例如 `0.5-001.bin`。代码将文件名转为小写，并取第一个 `-` 前的部分作为标签识别前缀。

|文件名前缀|标签|示例|
|-|-|-|
|包含 `z` 或 `normal`|0|`z-001.bin`、`normal-001.bin`|
|0.5|1|`0.5-001.bin`|
|1.0|2|`1.0-001.bin`|
|1.5|3|`1.5-001.bin`|
|2.0|4|`2.0-001.bin`|
|3.0|5|`3.0-001.bin`|
|5.0|6|`5.0-001.bin`|
|6.0|7|`6.0-001.bin`|

数值类别通过提取前缀中的数字和小数点识别，判断条件为与目标值的差的绝对值小于 `0.1`。建议严格使用表中的前缀，避免混入其他数字。无法识别的文件返回 `-1`，不会参与数据集生成。

这些数值的物理含义及单位由实际数据定义，代码中未指定。脚本支持 8 类映射，但不会检查输入是否包含全部 8 类。

## 5\. 处理流程

### 文件级分层划分

原始文件按约 **70% 训练集、20% 验证集、10% 测试集** 划分：

* 先从文件列表中划出 10% 测试文件。
* 再从剩余 90% 文件中划出 2/9 作为验证文件，其余作为训练文件。
* 两次划分均按文件标签设置 `stratify`，并使用 `random\_state=42`。
* 划分完成后，才在三个集合内分别预处理和切片；增强始终使用对应训练文件的数据。

比例针对**文件数量**，实际数量受取整影响。例如，若恰有 120 个可识别文件且类别分布满足分层划分条件，则得到 84 个训练文件、24 个验证文件和 12 个测试文件。

分层划分尽量保持文件类别比例；文件时长不同、处理失败或训练增强，都可能使最终切片数量和类别比例发生变化，因此输出样本数不保证符合 70% / 20% / 10%。

### 信号预处理

1. **读取信号**：将 `uint16` 原始数据转换为 `float32`。
2. **幅值提取**：计算 `abs(raw - mean(raw))`。代码将其称为包络，实际采用去均值后全波整流，没有使用 Hilbert 变换。
3. **降采样**：每 `decim\_rate` 个点取最大值。这是分块最大值操作，代码未包含专门的抗混叠低通滤波。
4. **小波去噪**：使用 sym4 进行 3 层分解，以最细层细节系数估计噪声标准差，对所有细节系数施加软阈值，保留近似系数并重构。
5. **去基线**：减去 2 秒窗口的均值滤波结果。

小波阈值按以下公式计算，其中 `N` 为整段降采样信号的长度，`cD1` 为最细层细节系数：

```text
sigma = median(abs(cD1)) / 0.6745
threshold = 0.40 × sigma × sqrt(2 × ln(N))
```

### 集合内切片

每个文件在预处理后独立切片，窗口长度为 10000 点，起点按 15000 点递增。默认时间窗口示例为 `\[0, 1)` 秒、`\[1.5, 2.5)` 秒、`\[3, 4)` 秒。

设预处理后的文件长度为 `L`，基础切片数为：

```text
若 L < slice\_len：切片数 = 0
否则：切片数 = floor((L - slice\_len) / step\_len) + 1
```

`build\_meta` 记录 `(文件路径, 切片起点, 标签)`，不缓存信号数组。生成 NPZ 时会重新读取并预处理相关文件。

### 训练集增强

仅训练集执行增强。验证集和测试集使用原始切片位置和固定长度，仍执行预处理、标准化及 FFT，但不进行随机平移、时间缩放或加噪。

设训练集中某类基础切片数量为 `n\_k`，最多类别的数量为 `n\_max`：

```text
目标数量 = 5 × n\_max
该类每个基础切片的候选样本数 = ceil(目标数量 / n\_k)
```

候选样本数包含原位样本，并非在原位样本之外再增加这么多。最多类别的每个基础切片产生 5 个候选样本；较少类别根据上述公式产生更多候选样本。

每个基础切片按以下顺序生成候选样本：

1. **时间平移**：先设置偏移 `0、-5000、+5000` 点，再追加 `\[-5000, 5000]` 内的随机整数偏移，直到达到候选样本数。随机偏移可以重复。
2. **时间缩放**：第一个原位样本取 `time\_scale=1.0`；其余候选样本随机取 `time\_scale∈\[0.9, 1.1)`，并计算 `extract\_len=int(slice\_len × time\_scale)`。
3. **边界检查**：从 `start\_idx + off` 开始提取 `extract\_len` 点，越界则跳过，不重试或补齐。
4. **恢复固定长度**：若提取长度与 `slice\_len` 不同，用 `np.interp` 进行线性插值，统一恢复到 10000 点。
5. **加入噪声**：除第一个原位样本外，对其他有效候选样本加入零均值高斯噪声；噪声标准差为插值后切片标准差的 1%～5%。

时间缩放实际提取约 0.9～1.1 秒的信号，再恢复为固定点数。系数小于 1 时，将较短片段拉伸；大于 1 时，将较长片段压缩。即使随机偏移恰好为 0，只要不是第一个候选样本，也仍执行时间缩放和加噪。

例如，若最多类别有 100 个训练基础切片，则各类目标为 500。某类有 60 个切片时，每个切片产生 `ceil(500 / 60)=9` 个候选样本，共 540 个候选，再由边界检查决定实际保留数量。

由于向上取整和边界跳过，最终类别数量不保证完全相等，也不一定恰好达到目标数量。同一训练文件内的增强样本可能相互重叠，但不会从验证或测试文件提取数据。

### 时域与频域特征

每个有效切片独立进行 Z-score 标准化：

```text
x\_time = (slice - mean(slice)) / (std(slice) + 1e-8)
```

这里使用整个切片的均值和标准差，不是在切片内部再做移动窗口归一化。

频域特征对标准化后的切片计算 FFT，取幅值并除以切片长度，保留前半部分，除直流分量外乘以 2。以默认输出采样率和固定长度计，5000 个频点对应 **0～4999 Hz**，分辨率为 **1 Hz**，不包含 5000 Hz 的 Nyquist 频点。时间缩放会改变增强样本的频谱分布。保存的是幅度谱，代码未计算功率谱或对数谱。

## 6\. 输出数据格式

每个 NPZ 文件包含以下数组，其中 `N` 为该子集实际保存的样本数：

|键名|默认形状|数据类型|内容|
|-|-|-|-|
|`x\_time`|`(N, 1, 10000)`|`float32`|标准化时域切片|
|`x\_freq`|`(N, 1, 5000)`|`float32`|单边 FFT 幅度特征|
|`y`|`(N,)`|`int64`|0～7 的类别标签|

三个数组的第一维一一对应。时间缩放后已恢复固定长度，因此所有样本的特征形状一致。代码使用 `np.savez` 保存，未启用 `np.savez\_compressed` 压缩；输出中不含源文件名、切片起点、增强偏移或时间缩放系数。

读取示例：

```python
import numpy as np

with np.load("./dataset\_sym4\_L3\_aug2/train.npz") as data:
    x\_time = data\["x\_time"]
    x\_freq = data\["x\_freq"]
    y = data\["y"]

print("时域形状：", x\_time.shape)
print("频域形状：", x\_freq.shape)
print("标签形状：", y.shape)

labels, counts = np.unique(y, return\_counts=True)
print("各类样本数：", dict(zip(labels.tolist(), counts.tolist())))
```

## 7\. 注意事项与常见问题

* **随机性**：文件列表已排序，两轮划分均使用 `random\_state=42`。随机平移、时间缩放和噪声使用 NumPy 全局随机数，但代码未设置其种子。需要复现时，可在 `main()` 开头加入 `np.random.seed(42)`，并保持输入文件、参数和依赖版本一致。
* **分层划分失败**：输入为空、某类文件太少，或划出的子集文件数少于类别数时，`train\_test\_split` 可能报错。这里需要足够的是每类独立文件数；一个文件切出很多窗口无法解决文件级分层样本不足。
* **没有可保存切片**：某个集合的文件全部过短或处理失败时，其样本列表为空，当前代码在构造 `xt`、`xf` 的三维数组时可能报错。运行前应检查数据时长和内容，必要时在保存前增加空集合检查。
* **内存或磁盘不足**：默认每个输出样本的两个特征数组共约占 60 KB，10,000 个样本仅特征就约占 600 MB；运行峰值还包括原始信号、列表和中间数组。大规模数据可考虑分批处理和保存。
* **缺少模块**：确认运行脚本和执行 `python -m pip install ...` 使用同一个 Python 环境。缺少 `pywt` 时安装 `PyWavelets`，缺少 `sklearn` 时安装 `scikit-learn`。
